# 发布计划：状态与交互

更新：2026-09-10。仅改动增长模块的发布计划及对应入口摘要，不调整主页分享、问卷分享、内容库或审核体系。

## 产品约定

- 发布计划是咨询师自主安排，不是平台派单。不采纳、不执行不影响其他功能。
- 生成只得到建议；采纳才创建任务；创作不等于发布。只有咨询师主动标记后才记录“已发布”。
- 当前使用按条件排布的规则示例，不宣称接入真实 AI，不自动向外部渠道发布。
- 数据按咨询师及演示场景隔离保存在本机。刷新后可以读取；不支持跨设备同步。读取异常不覆盖旧数据；写入失败保留当前输入。
- 原型默认数据包含 1 份待采纳建议及 2 份历史计划，用来直接演示“部分采纳、历史完成、过期未完成与迁移”交互；已有本机安排会原样保留，Mock 按稳定 ID 增量补齐且不重复添加。

## 入口和页面

增长首页「发布计划」固定存在，摘要根据当前数据展示：暂无安排、待采纳建议、周期及待完成数、已完成、上期已结束、手动安排。演示状态额外标明“演示”。

入口：`/counselor?tab=growth&plan=publish`。

页面包含「当前安排」「待采纳建议」「历史计划」；列表页始终可生成计划或手动添加。没有任何计划时也能直接添加任务。

## 生成与采纳

1. 选择起止日期（今天起，最长31天）、主题、渠道、形式、数量（1—14项）及可选发布星期。
2. 规则示例根据这些条件生成建议，显示推荐依据。不读取或编造咨询案例，不输出虚假“运营洞察”。
3. 可以逐项编辑标题、日期、渠道、形式、备注；更新周期会平移任务日期，不会直接创建任务。
4. 可以全选、部分勾选、稍后查看或放弃。部分采纳只创建勾选任务，未勾选项不创建；已有安排不被替换。
5. 日期已过或超出周期时不能采纳，须先调整。相同主题、日期、渠道的已有任务会二次提示，允许自主保留。
6. 放弃建议只处理建议，不影响正式任务。生成中支持取消，离开会清理生成计时器。

## 周期与任务是两个维度

| 对象 | 状态 | 操作 |
|---|---|---|
| 建议 | 待采纳／建议已过期 | 查看、调整、采纳、放弃 |
| 正式计划 | 未开始／进行中／已完成／无待办 | 查看任务、添加、编辑、改期 |
| 正式计划 | 已结束 | 查看历史，选择未完成任务迁移或取消，也可暂不处理 |
| 任务 | 待完成 | 编辑、改期、去创作、标记已发布、取消 |
| 任务 | 已发布 | 查看关联链接、纠正完成状态 |
| 任务 | 已取消 | 保留历史，不计入待完成与进度分母 |
| 任务 | 已迁移 | 保留原计划、新任务 ID 和新日期，不重复计数 |

日期为浏览器本地自然日，周期结束日当天仍有效。已过原定日期的待完成任务只给中性提示，不自动取消或标记失败。

历史任务批量迁移时统一选择新日期，创建独立任务，之后可逐项改期。新任务保存来源 ID，原任务保存迁移去向。周期不自动续期。

## 手动任务

必填标题、日期；渠道与形式可暂未确定。所属计划、关联内容 URL、备注可选。

- 默认独立任务，无须已有计划。日期超出所选计划时提示改日期或改为独立任务，不自动扩展周期。
- 保存后回到当前列表并定位任务。编辑覆盖原任务，不生成副本。
- 表单返回和取消时，未保存修改需要确认放弃；浏览器刷新或关闭时提示未保存。
- 独立手动任务可删除，删除需要确认；已完成任务保留历史，通过纠正完成状态恢复待完成。
- 标记已发布有确认页，发布链接可选。展示“由咨询师标记已发布，未验证外部平台结果”。
- 去创作携带任务标题，使用现有内容生成页面；返回时回到发布计划，不自动完成任务。

## Mock 演示

页面底部折叠「原型演示 · 切换状态」：全新咨询师、待采纳建议、当前有效计划、尚未开始、已过期计划、已过期建议、全部完成、仅手动任务。

默认显示“我的安排”原型数据，内含待采纳与历史记录；原型内容均使用明确的 Mock 标识和相对日期。演示场景独立保存；重置仅影响当前演示，不影响“我的安排”。首次加载与重置时以当天生成相对日期。刷新后默认回到“我的安排”，重选演示场景可恢复该场景已保存数据。

## 验证与实现边界

- 单元测试覆盖生成约束、部分采纳、重复采纳防护、过期拦截、周期边界、迁移溯源、任务校验、Mock、入口摘要和异常数据。
- 使用原项目暖白与紫色样式；仅发布计划范围新增样式，移动端保持48px操作目标。
- 本次采用 UI Design 的 Build 模式，按已确认的交互规则实现。读取：aesthetic-direction、design-guidelines，以及 buttons、colors、form-controls、navigation、surfaces、responsive-design、badges、border-radius、flexbox-layout、typography、general。浏览器验收使用 Playwright 技能。
- 正式上线还需要账号服务端存储、并发控制、AI接口、渠道授权及真实发布回执；此轮不将本机原型伪装为这些能力。
