# 咨询师「分享主页」交互说明

更新日期：2026-09-10。范围仅为增长页的主页管理、公开预览与分享路径，不重做问卷分享中心、排班、订单和 C 端首页。

## 入口与路径

- 增长 → 获客助手 → 分享主页：进入主页管理。
- 增长 → 我的主页 → 分享：进入同一分享页。
- 增长 → 我的主页 → 预览主页：进入同一用户视角预览。
- 可直达：`/counselor?tab=growth&profile=manage`。
- 编辑公开资料 → 保存 → 主页管理。
- 管理展示内容 → 勾选/取消、上下排序 → 保存 → 主页管理。
- 主页内容 → 文章详情或问卷 → 返回主页。
- 用户视角预览 → 阅读文章 / 完成问卷回看 → 返回预览。
- 分享主页 → 复制链接 / 系统分享 → 接收方公开主页 `/counselor/shared#…`。

## 保存与数据来源

| 数据 | 生产位置 | 消费位置 | 保存约定 |
|---|---|---|---|
| 个人简介、服务人群、擅长方向、咨询风格 | 本页编辑；我的 → 个人主页与档案 | 主页管理、档案、公开预览、分享快照 | 同一份咨询师资料；公开字段保存在当前浏览器，刷新恢复 |
| 姓名、头像、资质头衔 | 既有咨询师档案 | 本页只读、预览、分享快照 | 不在分享页另建一套身份资料 |
| 展示内容和顺序 | 管理展示内容 | 管理页、用户预览、接收方主页 | 只有点击保存才生效；允许全部取消 |
| 未提交的资料及展示选择 | 编辑过程 | 继续编辑 | 本机草稿；不会进入公开预览或分享快照 |
| 文章与问卷内容 | 当前演示内容库 | 内容详情及问卷体验 | 仅已发布条目可选择；未发布条目禁用 |
| 问卷作答 | 用户视角的问卷页 | 本次回答回看 | 内存临时保存，返回或刷新清除；不向咨询师发送 |

资料与展示设置分别保存。某一部分仍有草稿时，预览和分享使用各部分最近一次保存的版本。放弃修改仅恢复该部分的已保存版本，不删除已发布内容。

## 分享边界

- 实际调用浏览器剪贴板；失败时提示手动复制，不虚报成功。
- 支持系统分享面板的平台提供系统分享；不支持时使用链接分享。取消不显示发送成功。
- 接收方不依赖发送者的浏览器存储，链接携带白名单公开资料快照和已选内容 ID。
- 不序列化证件编号、财务信息、来访者记录等私有字段；简介为用户主动保存的公开文本，正式上线前仍需内容审查。
- 旧链接固定为分享时的版本，主页更新后需要重新分享；演示内容正文来自内置内容库。
- 这是可修改的演示快照，不具备身份认证或签名能力，接收页已明确标注。
- 当前本地链接只能在运行原型的电脑上访问，未发布到 Vercel。
- 未实现真实微信好友/朋友圈发送、图片海报、后端内容发布审核、服务预约与支付；删除了原来的假分享成功提示和假二维码。
- 简介整理为现有文本拼接示例，不调用 AI；问卷为自我探索演示，不是经验证的心理量表，不输出诊断与风险等级。

## 本轮验证

- 类型检查、构建及全部 64 项测试通过，其中新增 8 项公开字段、筛选排序、分享编码、异常存储测试。
- 浏览器完成：选择第三项并排序 → 保存 → 刷新 → 预览顺序一致。
- 完成文章阅读、问卷作答 → 回看 → 返回。
- 完成编辑草稿 → 返回 → 刷新 → 恢复草稿，已保存简介不受影响。
- 完成主页保存 → 刷新 → 我的档案回填；档案修改再同步回主页。测试简介已恢复。
- 完成取消全部内容 → 预览空态 → 恢复原有两项。
- 接收方链接已在独立页面打开并验证。剪贴板写入成功提示已验证；自动化浏览器虚拟剪贴板与页面剪贴板不互通，未声称端到端粘贴验证通过。
- 390 × 844 手机尺寸无横向溢出；底部管理、预览与分享按钮可见可达；桌面保持原有窄屏咨询师布局。
- 文章详情刷新后仍保持详情，浏览器返回可回到用户预览。
